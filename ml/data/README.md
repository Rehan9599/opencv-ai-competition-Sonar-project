# ml/data/ — not in git

The 34 GB of imagery lives outside the repo.

| Subdir | What | Where |
|---|---|---|
| `raw/` | 32 GB of source datasets, unmodified | not hosted — source URLs and download steps are in `ml/scripts/download_datasets.py` and `docs/hf/dataset_card.md` |
| `splits/` | 5,205 tiles (~1.8 GB) — assembled, preprocessed train/val/test | **public** — [rehan9599/drishti-sss](https://huggingface.co/datasets/rehan9599/drishti-sss), CC-BY-SA-4.0 |
| `processed/`, `synthetic/` | intermediate build outputs | regenerated by `ml/scripts/` |

The public dataset **excludes the 1,200 `crab_pot` hard-negative tiles** (gated source, class filtered
from the product). The shipped model trained on the full 6,405; to reproduce it exactly, rebuild from
the recipe below — `ingest_crab_pot` pulls the extra tiles when the source is available.

Rebuild `splits/` from scratch:
```bash
python ml/scripts/tile_subpipe.py
python ml/scripts/tile_ai4shipwrecks.py
python ml/scripts/build_dataset.py
python ml/scripts/build_synthetic_data.py --classes 3 --split train --count 900   # + val/test
python ml/scripts/build_synthetic_data.py --classes 4 --split train --count 350
python ml/scripts/preprocess_splits.py
```
