# Retained technical PDFs

These three PDFs contain supporting technical material for DRISHTI:

- `data and preprocessing.pdf` — sonar dataset preparation and the OpenCV preprocessing pipeline.
- `model.pdf` — detector choices and model experiments; segmentation is historical research, not the shipped model.
- `scale and limits.pdf` — operating assumptions, limitations, and deployment considerations.

They are retained as supplementary references. The current source of truth for implementation,
evaluation, and deployment is the repository code and the Markdown/YAML documents in `docs/`.
See [`../PDF_AUDIT.md`](../PDF_AUDIT.md) for the review of all six original PDFs. Three
legacy PDFs were removed because they contain stale contest/problem material; regenerate them
from contest-specific sources before restoring them to a public submission.
